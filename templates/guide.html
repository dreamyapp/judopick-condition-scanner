키움 REST API 키 발급 가이드

아래 순서대로 천천히 따라 하세요. 약 10분 정도 걸립니다.

✓

먼저 준비해 주세요

키움증권 계좌, 키움 홈페이지 아이디, 계좌 비밀번호, 본인 명의 휴대전화가 필요합니다.

키움 REST API 홈페이지 열기 키움 공식 발급 안내 열기
1

키움 REST API 사용을 신청합니다

  1. 위의 키움 REST API 홈페이지 열기를 누릅니다.
  2. 화면 오른쪽 위의 API 사용신청을 누릅니다.
  3. 키움 아이디로 로그인합니다.
  4. 약관을 읽고 동의한 뒤 신청하기를 누릅니다.
키움 계좌가 없다면키움 공식 계좌개설 안내 열기 →
2

계좌 App Key 관리로 이동합니다

  1. 로그인 후 API 신청/해지 메뉴로 이동합니다.
  2. 계좌 App Key 관리 탭을 누릅니다.
  3. 실제 영웅문 조건식을 사용하려면 실전투자 계좌를 등록합니다.
주의: “모의투자 App Key 관리”와 혼동하지 마세요. 실전용 키와 모의투자용 키는 서로 다릅니다.
3

현재 사용하는 인터넷 IP를 등록합니다

  1. 화면에 표시된 현재 나의 IP 숫자를 확인합니다.
  2. 그 숫자를 IP 주소등록 칸에 입력합니다.
  3. 오른쪽의 추가 버튼을 누릅니다.
연결 오류가 날 때인터넷 회선이나 장소가 바뀌면 IP도 바뀔 수 있습니다. 이 화면에서 새 IP를 다시 추가하세요.
4

사용할 계좌를 등록합니다

  1. 화면 아래의 계좌 등록하기 버튼을 누릅니다.
  2. 사용할 주식 계좌를 선택합니다.
  3. 계좌 비밀번호를 입력하고 확인을 누릅니다.
  4. 휴대전화로 받은 SMS 인증번호를 입력해 등록을 마칩니다.
안전 안내: 계좌 비밀번호는 키움 공식 홈페이지에만 입력하세요. 이 조건검색 앱은 계좌 비밀번호를 요구하지 않습니다.
5

App Key와 App Secret을 내려받습니다

  1. 등록된 계좌 오른쪽의 App Key 다운로드를 누릅니다.
  2. 그 아래의 App Secret 다운로드도 누릅니다.
  3. 다운로드 폴더에서 계좌번호_appkey.txt와 계좌번호_appsecret.txt 파일을 확인합니다.
매우 중요: 각 키는 한 번만 다운로드할 수 있습니다. 파일을 잃어버리지 말고 다른 사람에게 보내지 마세요.
6

발급받은 키를 이 앱에 입력합니다

  1. 이 가이드를 닫고 오른쪽 위 API 키 설정·변경을 누릅니다.
  2. 큰 파란색 다운로드한 키 자동 찾기 버튼을 누릅니다.
  3. 앱이 두 파일을 자동으로 찾아 입력하고 연결합니다.
  4. 못 찾는 경우에만 키 파일 2개 직접 선택을 누릅니다.

“개인 API 연결됨”이라고 표시되면 모두 끝났습니다.

그래도 어려우신가요?

키움금융센터 1544-9000에 “REST API App Key 발급 문의”라고 말씀해 주세요.
